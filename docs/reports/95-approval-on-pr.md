# 95 · PR 을 만들면 결재판

- 브랜치: `feat/95-approval-on-pr`
- 근거: 사용자 요청(2026-11-02) 「office 테마에서 재밌는거 더 추가할거없을까?」 제안 표에 「그렇게 다 모두 진행해」. docs/plan/spec.md 「작업 공간 기믹」.

## 목표

`gh pr create` 가 성공하면 Claude 가 PR 제목이 적힌 결재판을 들고 내 책상으로 온다. 그 PR 이 머지되면 결재판에 도장을 찍는다.

## 한 일

- PR 명령을 알아본다. `gh pr create` 의 제목은 `--title`/`-t`(따옴표 있든 없든, `=` 로 붙이든)에서 읽고, 제목이 없으면(`--fill`) 명령 자체를 쓴다. 세션에서 가장 최근에 만든 PR 과 그 뒤에 성공한 `gh pr merge` 를 찾고, 실패한 명령은 세지 않는다(`frontend/src/systems/officeApproval.ts`).
- 새 PR 이 1분 안의 일이면 Claude 가 결재판을 두 손에 들고 내 자리(접수대 건너편)로 간다. 걷는 길은 「나에게 물으러 올 때」 와 같고, 도착하면 결재판을 내려놓고 2.5초 뒤 자기 일로 돌아간다. 말풍선은 실제 활동을 그대로 보인다(`isoPeople.ts` 의 `visitMe`, `stepVisit`).
- 「나」 는 Claude 가 결재판을 들고 오는 동안 자리로 돌아와 앉는다.
- 결재판은 접수대 위 모니터 옆에 놓이고, 놓일 때 「📋 PR 제목」 이 책상 아래에 4초 뜬다. 책상 위에는 Claude 와 「나」 의 이름표가 떠서, 그 아래에 걸어야 가리지 않는다. 다음 PR 이 올 때까지 책상에 남는다(`frontend/src/components/iso/isoApproval.ts`).
- 그 PR 이 머지되면 나무 손잡이에 빨간 고무판이 달린 도장이 결재판으로 내려왔다 올라가고, 종이에 빨간 자국이 남으며 이름표가 다시 뜬다. 결재판이 오기 전에 머지되면 결재판을 놓은 뒤에 찍는다.
- 장소를 바꾸거나 화면을 새로 열면 심부름을 다시 예약한다. 사람들을 다시 놓아도 예약은 남고, 최신 PR 이 바뀔 때만 취소한다.
- 1분이 지난 PR 은 심부름 없이 결재판만 놓이고, 머지까지 됐으면 처음부터 도장 자국이 있다. Claude 가 막혀 30초 안에 오지 못하면 결재판만 놓인다.
- 공항 · 건설 현장 · 낚시터에는 결재판이 없다(`IsoWorld.setApproval` 은 사무실만 구현한다).
- 시험: 제목 읽기 · 명령 판별 · 최신 PR 과 그 뒤 머지 · 실패한 명령 · 심부름 도착과 끝 · 30초 상한(`officeApproval.test.ts`).
