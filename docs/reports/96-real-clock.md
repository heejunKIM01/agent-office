# 96 · 사무실이 진짜 시각을 따른다

- 브랜치: `feat/96-real-clock`
- 근거: 사용자 요청(2026-11-02) 「office 테마에서 재밌는거 더 추가할거없을까?」 제안 표에 「그렇게 다 모두 진행해」. docs/plan/spec.md 「작업 공간 기믹」.

## 목표

벽시계가 실제 시각을 가리킨다. 12~13시에는 쉬는 사람이 카페에서 도시락을 먹고, 19시 넘어 일하면 책상 스탠드가 켜지고 피자 상자가 놓인다.

## 한 일

- 시간대를 나눈다. 12시부터 13시 전까지는 점심, 19시부터 다음 날 6시 전까지는 밤이다. 오늘 밤은 19시부터 세고, 새벽에는 어젯밤 19시부터 센다(`frontend/src/systems/officeHours.ts`).
- 개발실 벽시계를 시침 · 분침 · 빨간 초침이 가운데 축으로 도는 모양으로 다시 만들었다. 매 프레임 컴퓨터 시각으로 바늘을 맞춘다. 시침은 분에 따라, 분침은 초에 따라 조금씩 나아간다(`isoFurniture.ts` 의 clock, `components/iso/isoTimeOfDay.ts`).
- 점심에는 라운지에서 쉴 사람이 카페로 가서 왼손에 도시락을 들고 오른손으로 떠먹는다. 말풍선은 라운지에서 쉴 때와 같다. 일하는 중이면 그대로 일한다(`isoPeople.ts` 의 setLunch, `isoCharacters.ts` 의 lunch).
- 밤에는 타자 치는 책상마다 스탠드가 켜진다. 스탠드는 모니터 오른쪽 뒤에 서고, 호박색 갓과 은은한 빛무리가 있다. 오늘 밤 일한 기록이 있으면 접수대 위에 뚜껑 열린 피자 상자가 놓인다.
- 실검증에서 처음 자리(Claude 책상 끝)는 Claude 머리에 가려 피자와 스탠드가 보이지 않았고, 옅은 갓은 흰 책상에 묻혔다. 그래서 스탠드를 모니터 뒤로 옮기고 색과 빛무리를 더했고, 피자를 접수대로 옮겼다.
- 공항 · 건설 현장 · 낚시터에는 없다(`IsoWorld.setLastWork` 는 사무실만 구현한다).
- 시험: 시간대 경계 · 바늘 각도 · 오늘 밤 일했나 · 새벽 · 마지막 작업 시각(`officeHours.test.ts`).

- 스탠드는 8개까지다. 아홉 명 넘게 동시에 타자 치면 나머지 책상은 켜지지 않는다.
