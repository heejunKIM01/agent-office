# 83 · 건설 현장

- 브랜치: `feat/83-construction-site`
- 근거: 사용자 요청(2026-10-27) — 테마 제안 표의 「🏗️ 건설 현장」에 「건설현장 아이디어로 진행해봐」. 계획 문서 83행.

## 목표

설정 「장소」에 세 번째로 건설 현장을 더한다. 에이전트가 일하는 모습이 공사로 보이고, 커밋할 때마다 건물이 한 층씩 올라간다. 코드는 사무실 · 공항과 따로 산다.

## 한 일

- 설정 「장소」에 🏗️ 건설 현장을 더했다(`utils/place.ts` 의 `site`). 선택지는 3열이고 설명에 현장 한 문장을 붙였다. 보기는 `place === "site"` 이면 현장을 만든다(`isoView.ts`). 문구는 `PlaceWords.site` 로 따로 받는다.
- 현장은 `components/iso/construction/` 안에서 도형(`siteSolids`), 색(`sitePalette`), 사람(`siteFigures`), 소품(`siteProps`), 크레인(`siteCrane`), 건물(`siteBuilding`), 장면(`buildSite`), 태그(`siteLabels`)를 따로 갖고 `siteWorld` 가 엮는다. 배치는 `constants/sitePlan.ts`, 자리 찾기 · 걷기 · 층 수는 `systems/siteWalk.ts`, 현장 말은 `systems/siteTalk.ts` 다.
- 태그의 말 규칙(멈춤 → 도구 → 생각 → 말 → 생각 시간)은 공항과 같아 `systems/placeTalk.ts` 로 꺼내 둘이 함께 쓴다. 공항 말은 그대로다(`airportTalk.ts` 가 감싼다).
- 현장(64×50): 펜스와 정문 · 안전제일 표지, 2단 현장 사무소 컨테이너와 계단, 도면 테이블, 공정표(할 일 막대), 휴게 텐트 · 벤치 · 정수기 · 간이 화장실, 자재 야적장(벽돌 · 철근 · 파이프 · 거푸집 · 슬래브), 굴착기와 흙더미 · 콘, 발전기, 타워크레인, 짓는 중인 건물.
- 사람: Claude 는 흰 안전모의 현장 소장, 나는 정장의 건축주, 서브에이전트와 다른 세션은 하이비즈 조끼의 작업자다(Explore 초록 · Plan 보라 · 범용 파랑 · 다른 세션 산호색 안전모). 작업자는 정문으로 들어와 도구 자리로 걷고, 끝나면 손을 흔들고 정문으로 나간다. 읽기 → 도면 테이블, 수정 → 건물 앞 비계, 명령 → 굴착기 옆, 웹 → 야적장, 계획 → 공정표, 질문 → 건축주 옆. 건물을 가로지르는 길은 옆으로 돌아간다. 턴이 끝나면 소장은 휴게 텐트에 앉고, 오래 쉬면 졸고, 대화를 정리할 때는 커피를 든다. 소장이 물으면 건축주가 전화를 받고(「☎️ 현장 호출」), 내가 질문을 보내면 건축주가 전한다(「📢 질문」).
- 태그는 안전모 스티커처럼 노란 바탕에 소장 · 건축주 · 작업자 번호(E- · P- · B- · C-)와 현장 말을 단다. 📐 도면 확인 · 🧱 시공 · 🚜 장비 가동 · 📦 자재 조달 · 📋 공정 회의 · 📞 건축주 호출 · 🤔 검토 중 · ⚠️ 작업 중단 · 👷 작업 완료!.
- 크레인 · 건물: 층 = 1층 + 커밋 수, 11층에서 멈춘다. 새 커밋마다 크레인이 야적장으로 돌아 슬래브를 들고 건물 위에 놓아 한 층 올린다. 처음 열거나 새로고침하면 그 층 수로 바로 서 있다. 아래층부터 벽 · 창이 끝나고 위 두 층은 골조와 녹색 안전망이다.
- 오른쪽 패널은 현장일 때 「현장 안내도」(8칸)다. 문구는 4개 언어로 넣었다.
- 시험: `siteWalk.test.ts`(경로가 건물을 피하는지 모든 자리 쌍 · 걷기 · 층 수), `siteTalk.test.ts`(현장 말 · 생각 · 멈춤).
